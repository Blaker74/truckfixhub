Peterbilt Computer Module & ECU Identification

A technician-first repository for electronic controllers used on Peterbilt heavy-duty trucks. The catalog is anchored to Peterbilt Model 579/567 VECU architecture and expands by engine, transmission and installed options.

Configuration matters: There is no single universal Peterbilt module list. Model year, engine, transmission, brake system, ADAS, sleeper and vocational options change the installed controllers. Verify the VIN/build and OEM service information before applying a location, connector or replacement procedure.

VECU — Vehicle Electronic Control Unit

VehicleGateway / control
📷 Peterbilt body-builder documentation illustrates the VECU electrical architecture. Use the OEM source for the original copyrighted visual.

What it does: Central vehicle-level electronic controller in later Peterbilt multiplex architecture. It coordinates vehicle inputs/outputs and communicates across multiple CAN networks with powertrain, cab and chassis controllers.

Diagnostic importance: Multiple unrelated faults can point toward shared VECU power, ground or network problems. Prove network integrity before replacing the controller.

Peterbilt 2021 Heavy Duty Body Builder Manual

CECU — Cab Electronic Control Unit

Legacy architectureCab
📷 Peterbilt legacy body-builder documentation provides CECU connector/input references.

What it does: Cab electronic controller used in earlier multiplex architectures. It processes cab switches/inputs and participates in vehicle network control.

Diagnostic importance: Do not confuse CECU-era architecture with later VECU trucks; wiring, nodes and programming strategy differ.

Peterbilt 2017 Heavy Duty Body Builder Manual

CMP — Primary Chassis Module

ChassisStandard on VECU trucks
📷 Peterbilt provides chassis-module location illustrations showing the primary module under the cab on the left side.

What it does: Controls major chassis functions including exterior lighting, fuel-level inputs and other configured vehicle functions.

Location: Peterbilt identifies the primary chassis module under the cab on the left-hand side of the over-bell mounting bracket on applicable 567/579 trucks.

Peterbilt Heavy Duty Body Builder Manual

CMS / SCM / OCM — Secondary Chassis Module

ChassisOptional
📷 Peterbilt provides an OEM location illustration for the optional secondary chassis module.

What it does: Adds chassis I/O capacity for configured options. Peterbilt documentation associates it with equipment such as additional lift axles, snow-plow functions and Body Builder CAN applications.

Location: Applicable 567/579 documentation places the secondary module above the left frame rail at the back-of-cab crossmember.

Peterbilt Heavy Duty Body Builder Manual

Engine ECM / ECU

Engine
📷 Physical controller depends on installed engine: PACCAR MX, Cummins or other supported configuration.

What it does: Controls engine fueling, combustion, torque and engine-mounted sensors/actuators and communicates powertrain data to the truck.

Diagnostic importance: Identify the engine before using module photos, pinouts or programming procedures. An MX engine ECU is not interchangeable diagnostically with a Cummins ECM.

Aftertreatment / Emissions Controller

Engine / emissions
📷 Controller name and physical package depend on engine/emissions family.

What it does: Controls or coordinates DEF dosing, DPF regeneration, exhaust sensors and SCR/aftertreatment functions depending on engine architecture.

Diagnostic importance: NOx, DEF, temperature or dosing faults do not automatically condemn the controller. Verify supply, wiring, sensors and actuators first.

TCM — Transmission Control Module

Transmission
📷 Appearance varies with PACCAR TX, Eaton Endurant/UltraShift, Allison and other installed transmissions.

What it does: Controls automated/automatic transmission operation, shift strategy and transmission actuators/sensors while exchanging torque and speed information with other ECUs.

Diagnostic importance: Confirm transmission make/model before applying connector or module-location information.

ABS / ESC ECU

BrakesStability
📷 Brake ECU depends on installed Bendix/WABCO or other brake-system specification.

What it does: Processes wheel-speed and braking information and controls antilock braking and applicable stability functions.

Diagnostic importance: Wheel-speed sensors, power/ground, CAN communication, valves and chassis changes can produce faults without an ECU failure.

ADAS Radar / Camera Controllers

SafetyBendix Fusion
📷 New Model 579 integrates camera/radar driver-assistance technology; exact hardware depends on option and generation.

What it does: Supports collision mitigation, lane-related functions and other advanced driver-assistance features on equipped trucks.

Diagnostic importance: Mounting, alignment/calibration, wiring and network communication must be checked before replacing radar/camera hardware.

Peterbilt New Model 579 technology source

Digital Instrument Display / Cluster

CabDriver display
📷 Peterbilt publishes imagery of the New Model 579 15-inch digital display.

What it does: Presents gauges, warnings, vehicle status, systems-check information and ADAS information to the driver.

Diagnostic importance: Missing display data can originate from the source ECU or network, not necessarily the display itself.

Peterbilt official digital-display source

Body Builder / Multiplex Controllers

VocationalBody CAN
📷 Body-control configuration is option-dependent. Peterbilt publishes a dedicated Body Builder Module programming guide.

What it does: Interfaces configured vocational equipment and body functions with truck electrical architecture.

Diagnostic importance: Aftermarket body wiring must be separated from OEM network/module faults during diagnosis.

Peterbilt 579 resources and body-builder documentation

Telematics / Remote PTO Network Controllers

Telematics
📷 Installed telematics hardware varies by model year and fleet specification.

What it does: Peterbilt VECU architecture identifies a dedicated K-CAN network for telematics and remote-PTO functions.
