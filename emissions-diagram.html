👇 THE BASIC DIAGNOSTIC ORDER

1. Save the evidence

  1. Record all active and inactive fault codes before clearing anything.
  2. Note DPF, DEF, check-engine, stop-engine and derate messages.
  3. Record operating conditions and relevant diagnostic data when available.

2. Check upstream causes

  1. Engine air, fuel or combustion problems can increase soot or reduce usable exhaust conditions.
  2. Exhaust leaks, wiring faults and implausible sensor information can affect aftertreatment operation.
  3. Do not assume the component named in the latest code is the original cause.

3. Follow the OEM fault path

  1. Use the exact engine, model year, aftertreatment generation and fault code.
  2. Compare commanded and actual values where the manufacturer procedure calls for it.
  3. Repair the proven root cause before repeatedly commanding regens or replacing expensive components.

📚 Soot vs. ash

🔥 Soot can be oxidized during regeneration

Soot is combustible particulate. If it keeps accumulating, diagnose why the engine or aftertreatment system cannot manage it rather than assuming the filter alone is the cause.

🪨 Ash does not disappear during a regen

Ash is non-combustible material that accumulates over time. When manufacturer maintenance limits call for DPF ash service, the filter requires the approved cleaning/service process rather than another attempt to burn ash away.

🔁 A parked regen is a procedure—not a universal repair

If a fault prevents regeneration, the system cannot create the required conditions, sensor information is implausible, or the concern is ash rather than soot, repeatedly commanding another regen does not correct the underlying cause.

Aftertreatment faults can be connected

An upstream engine problem can change soot production and exhaust temperature. Incorrect pressure or temperature information can affect regeneration decisions. DEF/SCR problems can create NOx-related complaints. That is why TruckFixHub keeps these guides connected instead of treating every fault as an isolated part failure.
