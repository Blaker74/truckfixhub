👇 Diagnostic order

1️⃣ SAVE THE EVIDENCE: Record all active/inactive faults, warning lamps, derate state, soot information, regen history and relevant operating data before clearing anything.
2️⃣ LOOK UPSTREAM: Engine air/fuel/combustion, turbo/charge-air and exhaust leaks can create downstream aftertreatment symptoms. The last code in the chain may not be the first cause.
3️⃣ PROVE THE MEASUREMENTS: Pressure, temperature and NOx data matter only if their sensors, tubes, wiring and connectors are trustworthy.
4️⃣ SOOT VS ASH: Soot can be oxidized during regeneration. Ash is non-combustible accumulation and requires the approved maintenance/service process when limits are reached.
5️⃣ REGEN IS A PROCEDURE: If a fault prevents regeneration or required conditions cannot be achieved, repeatedly commanding regens does not repair the cause.
6️⃣ DEF / SCR: Verify DEF condition, supply/dosing, required temperatures and sensor feedback before condemning the catalyst or NOx sensors.
7️⃣ FOLLOW THE EXACT OEM FAULT TREE: Engine family, model year and aftertreatment generation matter. Compare commanded versus actual values where required.
