♻️ DIESEL EMISSIONS

Follow the exhaust. Each stage has a different job.

1️⃣ ENGINE EXHAUST
The aftertreatment system can only work with the exhaust conditions the engine sends it
↓
2️⃣ DOC
Diesel Oxidation Catalyst — oxidizes certain exhaust constituents and helps create heat for aftertreatment
↓
3️⃣ DPF
Diesel Particulate Filter — captures particulate matter; regeneration burns accumulated soot
↓
4️⃣ DEF + SCR
DEF dosing and the SCR catalyst work together to reduce NOx
↓
5️⃣ SENSORS / OUTLET
Temperature, pressure and NOx feedback help the control system monitor aftertreatment operation
🌫️ DPF / regen problem?
Read all related faults and review soot/load data, differential-pressure information, exhaust temperatures and the conditions required for regeneration.
💧 DEF / SCR problem?
Check related codes and manufacturer procedures for DEF quality/level, dosing, pressure, heaters, lines and SCR performance.
📟 NOx code?
A NOx fault does not automatically prove a bad sensor. Verify the exact code, wiring and upstream/downstream system conditions.
🌡️ Temperature / pressure code?
Check the sensor circuit and whether the reading is plausible. A bad tube, hose, connector or wiring problem can mislead diagnosis.

Aftertreatment faults can be connected

A problem upstream can create symptoms downstream. Engine faults can affect soot production and exhaust temperature; inaccurate temperature or pressure information can affect regeneration decisions; DEF/SCR faults can create NOx-related complaints. Record all active and inactive codes and operating data, then follow the manufacturer’s diagnostic order instead of replacing the component named in the last code.

🧠 Simple rule: diagnose the system in order. Find the earliest cause you can prove—not simply the last fault that appeared.
⚠️ Exhaust and aftertreatment components can become extremely hot. Follow manufacturer safety procedures and allow components to cool before physical inspection.
