👇 Diagnostic order

1️⃣ SAVE THE EVIDENCE: Record all active/inactive faults, warning lamps, derate state, soot information, regen history and relevant operating data before clearing anything.
2️⃣ LOOK UPSTREAM: Engine air/fuel/combustion, turbo/charge-air and exhaust leaks can create downstream aftertreatment symptoms. The last code in the chain may not be the first cause.
3️⃣ PROVE THE MEASUREMENTS: Pressure, temperature and NOx data matter only if their sensors, tubes, wiring and connectors are trustworthy.
4️⃣ SOOT VS ASH: Soot can be oxidized during regeneration. Ash is non-combustible accumulation and requires the approved maintenance/service process when limits are reached.
5️⃣ REGEN IS A PROCEDURE: If a fault prevents regeneration or required conditions cannot be achieved, repeatedly commanding regens does not repair the cause.
6️⃣ DEF / SCR: Verify DEF condition, supply/dosing, required temperatures and sensor feedback before condemning the catalyst or NOx sensors.
7️⃣ FOLLOW THE EXACT OEM FAULT TREE: Engine family, model year and aftertreatment generation matter. Compare commanded versus actual values where required.

💧 DEF DOSING PROBLEM

DEF dosing requires the correct fluid, supply, pressure, temperature conditions, control and doser operation. Start with the exact fault—not the most expensive component.

1️⃣ DEF CONDITION: Verify appropriate DEF quantity and evaluate quality/contamination using manufacturer-approved methods. Do not judge fluid condition by appearance alone.
2️⃣ SUPPLY SYSTEM: Follow the exact application’s tests for tank, pickup, pump, lines, pressure and heating/thawing functions where applicable.
3️⃣ DOSER / DEPOSIT: Inspect the dosing area according to service information. Crystallized deposits may be evidence, but diagnose why correct dosing or decomposition was not occurring.
4️⃣ ELECTRICAL / CONTROL: Check power, grounds, wiring, connectors and command response for the relevant pump, heater and dosing components.
5️⃣ CONDITIONS TO DOSE: The controller may intentionally withhold dosing when required temperatures or operating conditions are not met. Determine command versus actual behavior.
6️⃣ VERIFY SCR OPERATION: After the proven fault is corrected, complete the OEM verification routine and confirm dosing/SCR performance.
DEF QUALITY → SUPPLY / PRESSURE → DOSER → ELECTRICAL → ENABLE CONDITIONS → SCR RESPONSE → VERIFY.
⚠️ Follow manufacturer handling and test procedures for DEF and hot exhaust components. Do not bypass emissions controls.

DEF WARNING LIGHT

Start with the warning, the fault codes and the actual DEF system condition.

What a DEF warning can mean

A diesel exhaust fluid warning can involve fluid level, fluid quality, temperature, dosing, sensors, wiring or another aftertreatment condition. The warning symbol by itself does not prove which component failed. Record the complete active fault-code picture before clearing anything.

🔎 Start here

1️⃣ CHECK THE BASICS — Verify the actual DEF level and look for contamination, incorrect fluid, obvious leaks, damaged lines or recently disturbed components.
2️⃣ READ ALL ACTIVE CODES — Save the complete SPN/FMI or manufacturer-specific faults. Note other emissions, NOx, temperature, pressure, dosing or communication codes occurring at the same time.
3️⃣ FOLLOW THE OEM TEST PATH — Determine whether the evidence points toward fluid quality/level, tank sensing, heating, supply/dosing, NOx feedback, wiring or another aftertreatment problem.

🚫 Don't assume adding DEF fixes every DEF light

If the tank is genuinely low, adding the correct fluid may be necessary. But a warning that remains with adequate fluid can require diagnosis. A level reading that does not match the tank, a quality-related fault, dosing problem, sensor fault, wiring issue or other aftertreatment condition can produce warnings that filling the tank alone will not correct.

📈 DPF DIFFERENTIAL PRESSURE PROBLEM

A pressure reading depends on the filter, pressure tubes/ports, sensor, wiring and operating condition. A code does not automatically mean the DPF is plugged.

1️⃣ RECORD DATA: Save faults and pressure values with engine off where applicable, at idle and at manufacturer-specified test conditions.
2️⃣ INSPECT THE SENSE PATH: Check pressure tubes/hoses and ports for plugging, cracking, melting, water/contamination, incorrect routing or swapped connections.
3️⃣ SENSOR / CIRCUIT: Use OEM electrical and plausibility tests before replacing the sensor. Verify power, ground/reference, signal and connector condition as applicable.
4️⃣ FILTER RESTRICTION: If the measurement system is proven trustworthy, evaluate DPF restriction/soot/ash condition by the exact service procedure.
5️⃣ LOOK UPSTREAM: If loading is excessive, diagnose why. Engine condition or failed regeneration can be the reason the DPF became restricted.
6️⃣ VERIFY: After repair/service, confirm pressure response is plausible across the specified operating range.
READING → TUBES / PORTS → SENSOR / CIRCUIT → PROVE RESTRICTION → WHY DID IT LOAD? → VERIFY.
⚠️ Aftertreatment components and pressure lines can be extremely hot. Allow safe cooling and follow OEM service procedures.

🌡️ EXHAUST TEMPERATURE SENSOR FAULT

Aftertreatment controls depend on believable temperature information. Diagnose sensor position, circuit and plausibility before replacing parts.

1️⃣ IDENTIFY THE SENSOR: Determine the exact EGT sensor position named by the fault. Multiple sensors can be used across DOC/DPF/SCR assemblies.
2️⃣ COLD-SOAK PLAUSIBILITY: Where the OEM procedure uses it, compare temperature readings after adequate cold soak. A large unexplained disagreement can help identify a suspect circuit or reading.
3️⃣ HARNESS / CONNECTOR: Inspect routing near hot exhaust, abrasion, melted insulation, terminal damage, corrosion and connector security.
4️⃣ ELECTRICAL TEST: Follow the exact manufacturer circuit/sensor test. Do not substitute generic resistance values or assumptions across different sensor designs.
5️⃣ SYSTEM EFFECT: Implausible EGT information can prevent or interrupt regeneration and can trigger related aftertreatment faults. Correct the measurement fault before chasing secondary symptoms.
6️⃣ VERIFY: Confirm the reading tracks plausibly through warm-up or the OEM verification procedure and that related faults stay cleared.
EXACT SENSOR → COLD PLAUSIBILITY → HARNESS → OEM CIRCUIT TEST → SYSTEM EFFECT → VERIFY.
⚠️ Exhaust sensors and housings can remain dangerously hot long after shutdown. Allow proper cooling before inspection or removal.

🔥 HIGH DPF SOOT LOAD

High soot load is a result. Determine why soot accumulated before treating regeneration as the repair.

1️⃣ SAVE THE STORY: Record faults, soot estimate, regeneration history, derate state and relevant pressure/temperature data before clearing anything.
2️⃣ WHY DID SOOT BUILD? Check for repeated interrupted regens, excessive idle/low-load operation and engine air, fuel or combustion problems that can increase soot.
3️⃣ CAN THE SYSTEM MEASURE CORRECTLY? Evaluate differential-pressure and exhaust-temperature information using OEM plausibility and circuit tests. Bad information can distort soot/regeneration decisions.
4️⃣ CAN IT CREATE REGEN CONDITIONS? Diagnose faults that prevent required temperatures, dosing or other manufacturer-defined enable conditions.
5️⃣ SOOT IS NOT ASH: Regeneration can oxidize soot. It does not remove non-combustible ash. Follow DPF maintenance/service limits for the exact application.
6️⃣ VERIFY: Correct the proven cause and confirm soot behavior and regeneration operation return to normal.
SOOT LOAD → WHY IT BUILT → SENSOR PLAUSIBILITY → REGEN ENABLE CONDITIONS → SOOT VS ASH → ROOT CAUSE → VERIFY.
⚠️ High soot loading can require manufacturer-specific restrictions on regeneration or service. Follow the exact OEM procedure before commanding a regen.

🧪 NOx SENSOR FAULT

A NOx-related code can involve the sensor, its electronics/circuit, exhaust conditions or SCR system performance.

1️⃣ IDENTIFY POSITION + CODE: Determine whether the fault concerns upstream or downstream sensing and preserve the complete SPN/FMI or manufacturer code.
2️⃣ CIRCUIT / COMMUNICATION: Inspect connector, harness routing, heat damage, power/ground and communication requirements using the exact wiring diagram and OEM test.
3️⃣ EXHAUST INTEGRITY: Exhaust leakage can change what a sensor sees. Inspect the relevant exhaust path before treating a measured value as isolated sensor failure.
4️⃣ PLAUSIBILITY: Compare sensor behavior with engine operating condition, temperatures and the other aftertreatment data the manufacturer uses for diagnosis.
5️⃣ SCR PERFORMANCE: A downstream NOx concern may reflect DEF dosing or catalyst performance rather than a failed downstream sensor. Follow the directed fault tree.
6️⃣ VERIFY: Complete any required reset/verification procedure and confirm the fault does not return under the specified conditions.
POSITION + CODE → CIRCUIT → EXHAUST INTEGRITY → PLAUSIBILITY → SCR / DOSING WHEN INDICATED → PROVE → VERIFY.
⚠️ NOx sensors and exhaust components operate in extreme heat. Follow manufacturer cooling, removal, installation and verification procedures.
