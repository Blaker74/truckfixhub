👇 PICK THE COMPLAINT

🌫️ It will not regen

  1. Read every active fault before forcing another regeneration attempt.
  2. Check whether an engine or aftertreatment fault is preventing regeneration.
  3. Review soot/load information, differential pressure and exhaust-temperature readings for plausibility.
  4. Verify the conditions required by the manufacturer for a parked or commanded regen are actually met.
  5. If regen starts but cannot complete, diagnose why temperature, flow or system performance is not reaching the required condition.

🐌 It is derated / losing power

  1. Record all active and inactive fault codes before clearing anything.
  2. Identify the earliest or root fault instead of chasing only the derate message.
  3. Check for engine air/fuel faults that may be creating excessive soot or poor exhaust conditions.
  4. Then evaluate DPF restriction, sensor plausibility, DEF/SCR operation and related wiring as directed by the fault path.
  5. Repair the proven cause and follow the manufacturer procedure for verification and derate recovery.

💧 DEF / NOx warning keeps coming back

  1. Write down the complete fault code and description.
  2. For DEF faults, verify fluid level/quality and inspect dosing, pressure, heaters and lines as applicable.
  3. For NOx faults, inspect wiring and connectors and compare sensor information with overall system conditions.
  4. Remember that an upstream engine, exhaust-leak or aftertreatment problem can make downstream readings look wrong.
  5. Do not replace a NOx sensor, doser or SCR component just because its name appears in a fault description.

Aftertreatment faults can be connected

A problem upstream can create symptoms downstream. Engine faults can affect soot production and exhaust temperature; inaccurate temperature or pressure information can affect regeneration decisions; DEF/SCR faults can create NOx-related complaints. Record all active and inactive codes and operating data, then follow the manufacturer’s diagnostic order instead of replacing the component named in the last code.
