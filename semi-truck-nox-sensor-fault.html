🧪 NOx SENSOR FAULT

A NOx-related code can involve the sensor, its electronics/circuit, exhaust conditions or SCR system performance.

1️⃣ IDENTIFY POSITION + CODE: Determine whether the fault concerns upstream or downstream sensing and preserve the complete SPN/FMI or manufacturer code.
2️⃣ CIRCUIT / COMMUNICATION: Inspect connector, harness routing, heat damage, power/ground and communication requirements using the exact wiring diagram and OEM test.
3️⃣ EXHAUST INTEGRITY: Exhaust leakage can change what a sensor sees. Inspect the relevant exhaust path before treating a measured value as isolated sensor failure.
4️⃣ PLAUSIBILITY: Compare sensor behavior with engine operating condition, temperatures and the other aftertreatment data the manufacturer uses for diagnosis.
5️⃣ SCR PERFORMANCE: A downstream NOx concern may reflect DEF dosing or catalyst performance rather than a failed downstream sensor. Follow the directed fault tree.
6️⃣ VERIFY: Complete any required reset/verification procedure and confirm the fault does not return under the specified conditions.
POSITION + CODE → CIRCUIT → EXHAUST INTEGRITY → PLAUSIBILITY → SCR / DOSING WHEN INDICATED → PROVE → VERIFY.
⚠️ NOx sensors and exhaust components operate in extreme heat. Follow manufacturer cooling, removal, installation and verification procedures.
