Semi Truck Won't Start

First separate a no-crank condition from an engine that cranks normally but will not start.

No crank

Check battery bank, terminals, cables, grounds, starter relay, neutral/clutch interlocks, start command, solenoid and starter.

Clicks but does not crank

Test batteries under load and perform positive- and ground-side voltage-drop testing before replacing the starter.

Cranks but will not start

Check ECM communication and power, fault codes, cranking RPM, fuel supply/pressure, crank/cam synchronization and injector control.
