How to Pressure Test a Semi-Truck Cooling System

Pressure testing applies controlled pressure to a sufficiently cooled system to reveal leakage. Always use the exact OEM pressure specification.

  1. Park safely and allow the engine to cool.
  2. Inspect coolant level and visible leaks.
  3. Install the correct tester/adapter.
  4. Apply only specified pressure.
  5. Observe pressure retention.
  6. Inspect radiator, hoses, tank, cap area, thermostat housing, water pump, heater lines and fittings.

If pressure drops without an external leak, investigate hidden/internal paths such as EGR cooler, oil cooler and internal engine leakage. Test the pressure cap separately where appropriate.

Never remove a pressure cap from a hot pressurized cooling system.
