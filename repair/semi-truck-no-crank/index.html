Semi Truck Won't Crank

A no-crank means the engine does not rotate when start is requested. Determine whether the starter has adequate power, ground and start command.

Silent

Check battery bank, fuses, relay, ignition/start switch, neutral or clutch interlock, wiring and solenoid.

One click

Check battery capacity, positive and ground voltage drop, starter connections, solenoid, starter and possible mechanical engine resistance.

Start command test

If proper command reaches the starter but it does not operate, starter/solenoid becomes a stronger suspect. If command is missing, work backward through relay, interlocks, transmission status, switch, wiring and modules.
