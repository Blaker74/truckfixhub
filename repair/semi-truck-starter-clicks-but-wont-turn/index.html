Starter Clicks but Won't Turn

First decide what kind of clicking you hear. Then test the high-current path instead of guessing at a starter.

🔨 ONE HEAVY CLICK

The solenoid or another part of the start circuit may be responding, but the starter motor is not turning the engine.

⚡ RAPID CLICKING

The circuit is repeatedly engaging and dropping out. Start by looking for voltage collapse, weak battery capacity or resistance in the main connections.

🧒 The simple picture

🔋 BATTERY → 🔌 CABLE → ⚙️ STARTER → 🚛 ENGINE → ⏚ GROUND

Starter current has to travel to the starter and return to the battery. Trouble anywhere in that loop can make a good starter look bad.

1. SEE IT — Watch what happens under load

Do the dash lights collapse? Does the clicking change? Does the starter connection receive voltage during the actual start attempt? Static voltage with no load does not tell the whole story.

2. NAME IT — Battery problem, path problem or starter/mechanical problem?

Check the battery bank's state of charge and condition. Inspect terminals, interconnects, main positive cables and grounds. Look for looseness, corrosion, heat damage and disturbed connections.

3. TEST IT — Use voltage drop while cranking

Loaded voltage-drop testing helps expose resistance that a visual inspection or continuity test can miss. Test the positive path and the ground return path using the correct procedure and application limits.

4. PROVE IT — Don't condemn the starter early

If battery capacity is adequate, loaded voltage reaches the starter, ground return is good and the proper start command is present, the starter/solenoid or mechanical resistance becomes a stronger suspect. Prove the circuit first.

🔨 One heavy click: work this order

  1. Battery bank charged and capable under load.
  2. Battery terminals and interconnect cables secure.
  3. Positive cable path tested under starter load.
  4. Ground return path tested under starter load.
  5. Starter connections secure and not heat damaged.
  6. Start command present when requested.
  7. Then investigate starter/solenoid and engine mechanical resistance.

⚡ Rapid clicking: work this order

  1. Check battery state of charge.
  2. Test individual batteries as appropriate.
  3. Inspect battery-to-battery interconnects.
  4. Inspect main positive and negative connections.
  5. Perform loaded voltage and voltage-drop tests.
  6. Only move deeper after the main power path is proven.

⚠️ Important

Heavy-truck battery circuits can deliver extremely high current. Secure the vehicle and use properly rated test equipment. Do not bypass safety interlocks or short starter terminals to force a crank.
