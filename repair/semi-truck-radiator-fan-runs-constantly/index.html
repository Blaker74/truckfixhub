Radiator Fan Runs Constantly

A fan that stays engaged can mean the truck wants the fan on, the control system has entered a protective strategy, or the clutch/control hardware is stuck. Do not begin by replacing the fan clutch.

🧒 Make it simple

🧠 TRUCK DECIDES
🔌 / 💨 COMMAND TRAVELS
⚙️ CLUTCH RESPONDS
🌀 FAN TURNS

Start at the decision and work toward the fan.

1. SEE IT — prove the fan is actually engaged

Document when the fan runs: cold start, warm idle, highway speed, A/C operation, regeneration, or only after a fault appears. Save active fault codes and relevant engine data.

2. NAME IT — commanded ON or not?

Use appropriate diagnostic data to compare fan command with actual fan behavior.

Commanded ON: find out why the controller wants fan.

Commanded OFF but fan remains engaged: move toward clutch, solenoid, air/electrical control and mechanical branches.

3. TEST IT — follow the correct branch

If commanded ON, inspect temperature inputs, A/C requests, aftertreatment/engine operating strategy and fault-related protective logic for the exact application.

If commanded OFF, verify the control signal reaches the clutch correctly and test clutch/control hardware using the manufacturer's procedure.

4. PROVE IT — reproduce the original condition

Repair the proven cause, clear faults where appropriate, then reproduce the condition. Verify the fan now engages and releases when the control strategy calls for it.

🔍 Evidence-first work order

  1. Confirm the complaint.
  2. Record whether the engine is cold or hot.
  3. Save fault codes before clearing anything.
  4. Compare commanded fan state with actual behavior.
  5. If commanded ON, determine the reason for the request.
  6. Validate relevant sensor inputs.
  7. Check A/C and application-specific fan requests.
  8. If commanded OFF, test the fan-control path.
  9. Test clutch operation using exact service information.
  10. Repair the proven cause and verify normal cycling.

🧩 Pattern clues

Fan engaged immediately on a cold start: inspect control strategy, faults and fail-safe behavior before assuming an overheating problem.

Fan commanded ON continuously: the clutch may simply be obeying the truck.

Fan commanded OFF but stays locked: hardware/control delivery becomes much more important.

⚠️ Exact control logic varies

Fan-clutch type, solenoid logic, air/electrical strategy, fail-safe state and commanded temperatures vary by engine and chassis. Use exact OEM information before applying power, air or bypass commands.

🛑 Safety

A cooling fan can engage unexpectedly and can cause severe injury. Keep hands, tools, clothing and test leads clear of the fan and rotating components.
