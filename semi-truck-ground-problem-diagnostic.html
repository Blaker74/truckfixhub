🔩 SUSPECTED BAD GROUND

A ground is not good because it looks good. The return path must carry current under load.

1️⃣ IDENTIFY THE RETURN PATH: Use the wiring information to find the actual ground point, splice, cable or module return for the failed circuit.
2️⃣ TEST UNDER LOAD: A continuity beep or unloaded voltage check can miss resistance. Use the approved loaded-circuit/voltage-drop method.
3️⃣ CHECK SHARED GROUNDS: If several systems fail together, determine whether they share a ground, splice, battery connection or chassis/engine bonding path.
4️⃣ INSPECT CONNECTION QUALITY: Look for corrosion, looseness, paint/rust at bonding surfaces, broken strands, heat, contamination and previous repairs.
5️⃣ REPAIR CORRECTLY: Restore the connection using the manufacturer-approved terminal, cable, sealing and fastening method rather than adding random jumper wires.
6️⃣ VERIFY UNDER LOAD: Repeat the voltage-drop test and operate the original load.
FIND REAL RETURN PATH → LOAD CIRCUIT → MEASURE DROP → LOCATE RESISTANCE → REPAIR CONNECTION → RETEST UNDER LOAD.
