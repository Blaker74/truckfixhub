🔊 CLUTCH NOISE

Pedal position is evidence. Do not diagnose a “clutch noise” until you know exactly when the sound begins and stops.

1️⃣ PEDAL UP: Record noise with the clutch fully engaged. Compare engine speed, transmission neutral/gear condition and vehicle movement.
2️⃣ LIGHT PEDAL CONTACT: Note whether the noise begins as the release system first loads. This can narrow the source toward release components.
3️⃣ FULLY DEPRESSED: Record whether the sound changes after full release and whether clutch-brake operation is involved where applicable.
4️⃣ ENGAGEMENT: If noise occurs only while taking off, inspect the complaint together with chatter, mounts and driveline movement.
5️⃣ SEPARATE TRANSMISSION INPUT: A noise that changes when torque to the transmission input changes may overlap with transmission/input-bearing concerns. Use the exact operating condition to isolate it.
6️⃣ INSPECT EVIDENCE: Check release mechanism, bearing, fork/cross-shaft, clutch assembly and related components using the manufacturer procedure.
7️⃣ VERIFY: Reproduce the exact pedal position and operating condition after correction.
PEDAL UP → LIGHT CONTACT → FULL RELEASE → ENGAGEMENT → CLUTCH VS TRANSMISSION → INSPECT → VERIFY.
