🔁 U-JOINT KEEPS FAILING

A repeat failure means look beyond the replacement joint.

1️⃣ PRESERVE EVIDENCE: Note failed caps, lubrication, heat, rust dust, looseness and abnormal wear before cleaning.
2️⃣ APPLICATION / INSTALLATION: Confirm correct joint, retention hardware, yoke condition and exact installation procedure.
3️⃣ YOKES: Inspect bores/ears and retention surfaces for wear, distortion or cap movement.
4️⃣ SHAFT / PHASING: Inspect damage, runout evidence, balance weights and correct shaft phasing/configuration.
5️⃣ SUPPORT / SLIP: Carrier-bearing or slip-spline problems can transfer abnormal load into the joint.
6️⃣ RIDE HEIGHT / ANGLES: Verify specified ride height and driveline geometry using exact manufacturer guidance—not a generic universal angle.
7️⃣ ROOT CAUSE: Correct why the joint failed before returning the truck to the same operating condition.
FAILURE EVIDENCE → APPLICATION → YOKES → SHAFT / PHASING → SUPPORT / SLIP → RIDE HEIGHT / ANGLES → ROOT CAUSE.
