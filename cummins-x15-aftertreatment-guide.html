Cummins X15 Aftertreatment

DPF • DEF • SCR • NOx sensors • Regen • Derate

How the system works

Modern Cummins heavy-duty aftertreatment uses a diesel oxidation catalyst and diesel particulate filter to address particulate matter, while DEF is introduced upstream of the SCR catalyst to reduce NOx. Sensors and electronic controls monitor system operation.

When an X15 has an emissions fault

  • Record all active and inactive fault codes before clearing anything.
  • Note DEF, DPF, check-engine, stop-engine and derate messages.
  • Inspect for obvious exhaust leaks, damaged wiring/connectors and DEF contamination.
  • Do not assume the component named in a fault description is automatically defective.
  • Use the correct Cummins/OEM diagnostic procedure for the engine calibration and model year.

DPF and regen

Repeated or unsuccessful regenerations can be symptoms of another problem. Soot loading, differential-pressure information, temperature information, duty cycle and related engine faults all matter when diagnosing why regeneration is not completing normally.

DEF, SCR and NOx

DEF purity and concentration matter to SCR performance. A low-conversion or NOx-related fault can involve dosing, sensors, exhaust integrity, catalyst performance or other conditions, so testing should come before parts replacement.
