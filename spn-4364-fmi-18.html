TRUCKFIXHUB FAULT CODE GUIDE

SPN 4364 FMI 18

SCR NOx conversion efficiency below the expected range.

What does it mean?

This fault generally indicates the engine/aftertreatment controller has determined that the SCR system is not reducing NOx as effectively as expected. The code identifies a system performance problem; it does not by itself prove that a particular sensor or component has failed.

Areas commonly involved in diagnosis

  • DEF quality, contamination or concentration
  • DEF dosing quantity and doser operation
  • Upstream and downstream NOx sensor readings
  • Exhaust leaks that affect sensor readings
  • SCR catalyst performance
  • Related active aftertreatment faults
  • Temperature and operating conditions required for SCR evaluation

Before replacing parts

Record every active and inactive code, confirm the engine and aftertreatment configuration, inspect for obvious exhaust/DEF problems, and follow the OEM diagnostic procedure. A NOx-related fault does not automatically mean the NOx sensor should be replaced.

Derate warning

Emissions faults can progress to inducement or derate conditions. Dashboard warnings and operating restrictions should not be ignored. Follow the vehicle manufacturer's instructions and seek qualified repair assistance when required.
