⚙️ ENGINE

A diesel needs four basics to run correctly.

💨 AIR
Enough clean air in and exhaust out
⛽ FUEL
Correct fuel supply and injection
🔥 COMPRESSION
Enough cylinder pressure and mechanical condition
🧠 CONTROL
Power, grounds, sensors and commands
🔇 CRANKS BUT WON’T START — Ask: Do I have fuel? Air? correct cranking speed? engine position information? active faults?
🐌 LOW POWER — Ask: Is air restricted? boost leaking? fuel supply weak? exhaust restricted? derate active?
🌫️ SMOKE — Color and operating condition matter. Check air/fuel balance, temperature and mechanical condition before guessing.
🌡️ RUNS HOT — Move to the Cooling diagram and verify coolant flow, airflow and fan operation.
⚠️ CHECK ENGINE LIGHT — Read the complete fault code first, then use the Fault Code diagram.
🧠 Simple rule: prove which basic is missing before replacing a component.
⚠️ Keep hands, clothing and tools away from belts, fans and other moving components while the engine is running.
