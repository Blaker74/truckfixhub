# TruckFixHub

TruckFixHub is a mobile-first heavy-duty truck troubleshooting and organization platform for drivers, technicians, parts professionals, fleets, and repair operations.

## Production foundation

The active public site is built from the current `main` branch and uses `index.html` as the canonical homepage. The modern TruckFixHub interface is supported by `assets/truckfixhub-ui.css` and the current repair, diagnostic, directory, community, and private-workspace pages.

### Public core
- Repair Library and troubleshooting catalog
- SPN/FMI fault-code references
- Detroit and Cummins diagnostic guides
- Cooling, electrical/starting, emissions, air/brake, and transmission troubleshooting
- Truck repair shop directory
- Resources and fuel-cost calculator
- About, Contact, Privacy, Safety, and TruckFixHub Standards

### Private/workspace tools
Customer records, VIN/garage records, repair intake, Repair Inbox, appointments, call notes, and repair workspace are application tools and should not be treated as public SEO landing pages.

### Panta AI
Panta AI is intentionally not part of the active paid offering until the AI service, metering, credits, payment flow, failure handling, and account persistence are verified end-to-end. Do not advertise or sell Panta Credits before that production path is proven.

### Legacy policy
Legacy URLs may remain only when they provide a safe redirect to a current destination. Legacy redirect pages should remain `noindex` and should not be added to the sitemap. Do not restore an obsolete homepage or duplicate library as an active search surface.

### Search and advertising
- Canonical domain: `https://truckfixhub.com/`
- Public sitemap: `/sitemap.xml`
- Crawler rules: `/robots.txt`
- Authorized seller record: `/ads.txt`
- AdSense publisher ownership code is maintained on the canonical homepage.
- Thin gateways, private tools, test pages, unfinished AI surfaces, and obsolete redirects should stay outside the monetized/indexable editorial inventory.
- User-generated Community content should not receive automatic AdSense placement until moderation controls are considered sufficient.

## Operating standard

Preserve safety and integrity before traffic, monetization, speed, or novelty. Diagnostic content should help users test and prove a fault rather than encourage unnecessary parts replacement, unsafe bypasses, or emissions-system defeat.
