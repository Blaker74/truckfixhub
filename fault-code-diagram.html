WHAT parameter or system area?

FMI
WHAT KIND of condition?

On J1939-equipped heavy-duty vehicles, the SPN identifies the parameter associated with the fault information and the FMI describes the failure mode or type of condition being reported. You need both pieces—and the correct manufacturer service information—to diagnose accurately.

🔎 Before touching a part

1️⃣ RECORD THE COMPLETE CODE — Save the SPN, FMI, source/module if available, active or inactive status, occurrence count and any manufacturer-specific code information.
2️⃣ SAVE THE WHOLE FAULT PICTURE — Multiple active codes can be related. Low voltage, lost communication, shared power/ground problems or one failed system can create several symptoms.
3️⃣ CHECK THE CONDITIONS — Note when the fault occurs: key-on, cranking, idle, loaded, hot, cold, during regen, over bumps or intermittently.
4️⃣ GO TO THE SYSTEM — Use the code to choose the correct diagnostic branch, then test power, ground, wiring, connectors, sensors, mechanical conditions or other items required by the OEM procedure.
5️⃣ PROVE THE REPAIR — Correct the root cause, follow the manufacturer's clearing/verification procedure and confirm the fault does not return.

🚫 A fault code is not automatically a bad part

A code can report what the control module detected without proving why it happened. Wiring damage, poor connections, low voltage, shorts, opens, mechanical problems, air or fluid issues, communication faults and other causes may produce a code associated with a component. Test before replacing.
