⚠️ FAULT CODES

Don’t let the code scare you. Break it into pieces.

SPN + FMI = WHERE + WHAT
1️⃣ READ THE CODE
Example: SPN 4364 FMI 18
↓
2️⃣ SPN
Points you toward the system, component, or data item.
↓
3️⃣ FMI
Describes the type of problem the module is reporting.
↓
4️⃣ VERIFY BEFORE REPLACING
Check wiring, connectors, power, grounds, air/fluid flow, and related symptoms before buying parts.

🧠 Think of it this way

SPN: “Where should I look?”

FMI: “What kind of trouble was detected?”

Together: They give you a starting point — not automatic permission to replace a part.

🔎 LOOK UP A CODE🤝 ASK COMMUNITY
⚠️ A fault code is a clue. Diagnose the cause before replacing parts.
