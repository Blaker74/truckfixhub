SPN 4334 — DEF Dosing / Pressure

Use the exact FMI and OEM definition first. A DEF pressure/dosing fault can come from fluid supply, restriction, leakage, electrical control, pressure feedback or a failed delivery component. Prove which part of the system cannot meet the commanded condition before replacing parts.

Key visual rule: A DEF dosing-pressure code identifies a system that is not producing or reporting the expected condition. It does not automatically identify the pump, doser or pressure sensor as the failed part.
OEM information: Exact SPN 4334 FMI meanings, pressure specifications, test routines and component architecture vary by engine and aftertreatment system. Use the applicable OEM procedure and specifications for the truck being diagnosed.
