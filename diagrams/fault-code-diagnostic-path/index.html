SPN / FMI Fault Code: Visual Diagnostic Path

A fault code tells you what the electronic system detected. It does not automatically tell you which part to replace. Use the complete code to choose the next test.

SPN = WHAT parameter is involved   +   FMI = HOW it is reported abnormal
START — Capture the complete faultRecord SPN + FMI together, controller/source when available, active/inactive status, warning lamps, derate and the truck's actual symptom.
↓
1. Is the fault ACTIVE?Do not erase useful evidence before recording it.
↓
ACTIVE
Diagnose the present conditionRecord operating conditions and related active faults. The problem may be available to test now.
INACTIVE
Look for the conditions that set itIntermittent wiring, connection, voltage, temperature, load or operating conditions may matter. History alone does not prove a current failed part.
↓
2. Are multiple faults present?
↓
YES
Find what they shareLook for common power, ground, network, harness, connector, system condition or one upstream failure that can explain several codes.
NO
Focus the systemUse the SPN/FMI and symptom to identify the circuit or system that needs testing.
↓
3. Does the FMI point toward an electrical condition?Examples can include voltage high/low, current high/low, open/short or abnormal signal behavior. Exact FMI interpretation must match the OEM/controller.
↓
ELECTRICAL PATH
Prove the circuitInspect connectors and harness condition, then test appropriate power, ground, signal, resistance/continuity or voltage drop using the correct OEM procedure.
PERFORMANCE / DATA PATH
Prove the reported conditionCompare sensor/data behavior with the physical system: pressure, temperature, flow, level, mechanical operation or other relevant evidence.
↓
4. Does testing prove the named component failed?
↓
NO
Do not replace it yetContinue upstream/downstream testing. A sensor may accurately be reporting a real system problem, or the circuit feeding it may be the fault.
YES
Repair the proven failureRepair wiring/connection/system fault or replace the component only after the evidence supports it.
↓
VERIFY THE REPAIRClear faults only at the appropriate point, recreate the original operating condition when practical, confirm the code stays inactive and verify the original symptom is gone.
TruckFixHub rule: Never turn “SPN ####” directly into “replace this part.” The complete SPN/FMI, controller, truck configuration, symptoms, related faults and test results belong in the diagnostic record.
