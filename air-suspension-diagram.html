👇 Follow the pattern

⬇️ WHOLE SUSPENSION WON’T AIR UP: Verify vehicle air pressure and common dump/height-control paths before condemning multiple bags.
↘️ ONE SIDE / CORNER LOW: Start local—bag, line, fitting, linkage and nearby mechanical condition—then trace upstream if local parts prove good.
📉 LEAKS DOWN PARKED: Map what drops and how fast. One corner suggests local; multiple bags together point toward shared plumbing/control.
📏 RIDE HEIGHT WRONG: Do not adjust the valve to hide worn/bent parts. Verify the exact spec, air/dump state, linkage, bags and axle-location components first.
🎈 REPEAT AIR-BAG FAILURE: Read the failure pattern. Check rubbing, clearance, ride height, travel control, mounts and axle location before installing another bag.
⬇️ DUMP CONTROL: Separate missing command from a valve that receives the correct command but does not respond. Then prove the pneumatic path.

🧠 Local or shared?

1️⃣ One corner: start at that local branch.
2️⃣ One axle/group: identify plumbing/control shared by that group.
3️⃣ Everything: verify common vehicle air supply and dump/height-control functions.
4️⃣ Holds air but geometry is wrong: inspect mechanical axle location and measure ride height by exact specification.

🎈 AIR BAG KEEPS FAILING

A repeat air-spring failure usually means the replacement part is being asked to live with an uncorrected condition.

1️⃣ READ THE FAILED BAG: Record the exact failure location and pattern—rub-through, cut, fold damage, bead/mount area, overextension evidence or heat/chemical damage.
2️⃣ CLEARANCE: Inspect nearby frame, tire, bracket, line and hardware through suspension travel. Witness marks can reveal intermittent contact.
3️⃣ RIDE HEIGHT: Incorrect height can place the spring outside its intended operating range. Verify the exact application specification.
4️⃣ TRAVEL CONTROL: Inspect shocks, limiting components and mounts as equipped. Excess extension/compression can damage the spring.
5️⃣ AXLE LOCATION / MOUNTS: Worn bushings, torque rods, shifted/bent mounts or incorrect installation can force the bag to operate misaligned.
6️⃣ VERIFY: Correct the cause before installing the replacement and inspect clearance/alignment through normal suspension movement.
FAILURE PATTERN → CLEARANCE → RIDE HEIGHT → TRAVEL CONTROL → AXLE LOCATION / MOUNTS → CORRECT CAUSE → REPLACE → VERIFY.
⚠️ Depressurize and mechanically support the vehicle according to manufacturer procedures before air-spring service.

⬇️ DUMP CONTROL / VALVE PROBLEM

If the suspension will not inflate—or will not dump—diagnose the command and pneumatic path before replacing the valve.

1️⃣ DEFINE THE FAILURE: Won’t dump, won’t reinflate, dumps by itself, intermittent, or only under a certain key/parking-brake/vehicle condition?
2️⃣ KNOW THE SYSTEM: Identify whether the application uses pneumatic, electric/pneumatic or electronically managed dump control and what interlocks are designed into it.
3️⃣ COMMAND: Verify the switch/module command and relevant power, ground, signal or pneumatic pilot supply using the exact wiring/air diagram.
4️⃣ VALVE RESPONSE: Confirm whether the control valve actually changes state when commanded. A correct command with no response is different from a valve that is never being told to move.
5️⃣ AIR PATH: Inspect supply, exhaust, lines and height-control interaction. Restricted or misrouted plumbing can imitate a failed dump valve.
6️⃣ VERIFY: Cycle dump and reinflate functions through the manufacturer-defined operating conditions and confirm correct ride height.
DEFINE FAILURE → SYSTEM DESIGN → COMMAND → VALVE RESPONSE → AIR PATH → HEIGHT CONTROL → CYCLE / VERIFY.
⚠️ Dumping the suspension can lower the chassis suddenly. Keep personnel clear and mechanically support the vehicle before service.

📉 AIR SUSPENSION LEAKS DOWN PARKED

The pattern of what drops is a map to the leak.

1️⃣ RECORD THE PATTERN: One corner, one axle/group or the whole suspension? Record starting height/pressure condition and how long the drop takes.
2️⃣ LOCAL VS SHARED: One corner suggests a local branch first. Multiple bags dropping together points toward plumbing or controls shared by those bags.
3️⃣ LEAK TEST: Use an approved leak-detection method on bags, fittings, lines, valves and connections. Flex/movement-related leaks may require inspecting the suspension through its normal travel.
4️⃣ CONTROL VALVES: A height-control or dump circuit can leak internally or exhaust when it should not. Follow the exact system’s isolation/test procedure before replacing a valve.
5️⃣ REPAIR THE PROVEN LEAK: Do not replace every bag or valve because the truck sits low by morning.
6️⃣ REPEAT THE PARKED TEST: Restore the same starting condition and confirm the previous leak-down pattern is gone.
MAP WHAT DROPS → LOCAL OR SHARED → LEAK TEST → CONTROL / DUMP CIRCUIT → REPAIR PROVEN SOURCE → REPEAT TEST.
⚠️ A leaking suspension can lower the chassis without warning. Support the vehicle mechanically before working beneath it.

↘️ ONE SIDE / ONE CORNER LOW

When only one area is low, start local before blaming the vehicle’s entire air system.

1️⃣ DEFINE THE AREA: One bag, one corner, one side or one axle group? Note loaded/unloaded condition and whether height changes after driving.
2️⃣ AIR SPRING: Inspect the local air spring for leakage, damage, rubbing, incorrect seating or structural concerns using approved methods.
3️⃣ LOCAL PLUMBING: Inspect nearby line, fitting, tee and connection points. Trace backward only after the local branch is checked.
4️⃣ CONTROL / LINKAGE: Inspect height-control linkage and valve arrangement for damage, incorrect mounting or lost motion. Some systems control groups rather than individual corners.
5️⃣ MECHANICAL SUSPENSION: A bent/broken mount, spring component, bushing, torque rod or axle-location problem can create an apparent ride-height issue even when the bag holds air.
6️⃣ VERIFY: Restore the exact application’s specified ride height and confirm it remains correct through suspension movement and the original operating condition.
IDENTIFY LOW AREA → LOCAL BAG → LOCAL PLUMBING → CONTROL / LINKAGE → MECHANICAL LOCATION → SPECIFIED HEIGHT → VERIFY.
⚠️ Never work under a chassis supported only by air springs. Mechanically support the vehicle before inspection or repair.

📏 RIDE HEIGHT IS WRONG

Ride height affects more than appearance. It can affect axle geometry and driveline operating angles.

1️⃣ GET THE RIGHT SPEC: Identify chassis/suspension configuration and use the exact manufacturer measurement points and target specification.
2️⃣ VERIFY AIR SUPPLY: Make sure the suspension has adequate air and is not being held in a dump condition.
3️⃣ INSPECT LINKAGE / VALVE: Check height-control linkage, mounting and valve operation for damage, looseness or incorrect setup.
4️⃣ AIR SPRINGS + MECHANICAL PARTS: Inspect bags, mounts, bushings, torque rods and axle-locating parts. Do not adjust a valve to hide bent, worn or broken hardware.
5️⃣ ADJUST BY PROCEDURE: Use the specified settling/cycling and measurement procedure. Small linkage changes can create large chassis-height changes.
6️⃣ VERIFY GEOMETRY: After correcting ride height, verify related alignment/driveline concerns when the original complaint included tracking, vibration or unusual tire wear.
EXACT SPEC → AIR / DUMP STATE → LINKAGE / VALVE → BAGS / MECHANICAL → ADJUST → SETTLE / REMEASURE → VERIFY RELATED GEOMETRY.
⚠️ Do not work beneath an air-supported chassis. Support it mechanically and follow current suspension manufacturer procedures.
