👇 The basic electrical path

1️⃣ POWER: Is the correct source voltage available when the circuit is supposed to operate?
2️⃣ PROTECTION / CONTROL: Is the fuse/circuit protection correct, and is the switch, relay, module or driver commanding the circuit?
3️⃣ PATH: Can the wiring, terminals and connectors carry the required current without excessive resistance?
4️⃣ LOAD: Is the component receiving the correct command and electrical supply under the actual operating condition?
5️⃣ GROUND / RETURN: Can current make the complete return trip under load?

🧠 Match the test to the complaint

⬛ COMPLETELY DEAD: Identify what else is dead with it. Shared fuses, feeds, grounds, connectors, network communication or module power can connect several symptoms.
💥 FUSE KEEPS BLOWING: Never install a larger fuse. Determine when the overcurrent occurs, isolate the affected branch and inspect for shorts, damaged wiring, water, heat or a failing load.
👻 INTERMITTENT: Record whether heat, vibration, moisture, harness movement or vehicle operation changes the symptom. Test while the failure is present whenever practical.
📉 VOLTAGE PRESENT BUT WON’T WORK: Open-circuit voltage alone does not prove current-carrying ability. Use the manufacturer-approved loaded-circuit and voltage-drop methods for the application.
🔩 SUSPECTED GROUND: Treat the return side as part of the circuit. Corrosion, loose connections, damaged cables and poor bonding can create resistance that a simple visual inspection misses.
