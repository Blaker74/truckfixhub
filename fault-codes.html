A code is the beginning of the diagnosis

SPN identifies the parameter or item being reported within the J1939 diagnostic framework. FMI describes the type of detected failure or condition. Exact interpretation and troubleshooting still depend on the controller, engine, calibration and vehicle configuration.

When the exact definition is uncertain, TruckFixHub does not guess. Capture the complete code and verify it against current information for the exact vehicle.

Before replacing a sensor or module

  • Determine whether the code is active, intermittent or previously logged.
  • Look for related codes and identify which fault may have occurred first.
  • Check system voltage, power and grounds where they can affect the complaint.
  • Inspect connectors, terminals and harness routing for damage, corrosion, looseness or chafing.
  • Compare available live data with the actual operating condition and other related sensors.
  • Test the system or circuit before condemning the component named in the code description.
  • After repair, clear faults when appropriate, operate the vehicle under the relevant conditions and verify the code does not return.
