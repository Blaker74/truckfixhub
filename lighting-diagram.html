👇 Follow the pattern

⬛ ONE LIGHT OUT: Confirm the function is commanded. Inspect that lamp/LED, connector, loaded power and return path. Stay local until evidence sends you upstream.
🚫 SEVERAL LIGHTS OUT: List exactly what works and what does not. Look for a shared fuse, feed, ground, connector, harness section, switch input or module output before testing every lamp.
✨ DIM / FLICKERING: Note whether engine speed, bumps, vibration or another electrical load changes the symptom. Loaded voltage-drop testing can expose resistance that an unloaded voltage reading misses.
💥 FUSE OPENS: Use only the specified protection rating. Inspect the protected branch for rub-through, pinching, moisture, damaged loads or a short. A fuse is evidence of excessive current—not the cause.
🔀 LIGHTS INTERACT: If brakes, turns or markers change another lamp, shared power or return paths deserve attention. Poor grounds can create backfeed and strange cross-circuit behavior.
🧠 MODULE-CONTROLLED LIGHT: Save faults and identify the exact controlled output. A module-related code can describe an open/short/load problem and does not automatically prove the module failed.

🧪 The test that prevents false answers

TEST UNDER LOAD. A damaged or corroded connection can show nearly normal voltage when almost no current is flowing. When the circuit design and manufacturer procedure allow it, test power and return while the load is operating and use voltage drop to locate unwanted resistance.
TRAILER BOUNDARY TEST. For trailer lighting, verify the requested function at the tractor-to-trailer connector. Correct output moves diagnosis onto the trailer. Missing output keeps the search on the tractor side.
INTERMITTENT TEST. Reproduce the condition before disturbing connectors. If safe movement of a harness, cab, hood or connector changes the fault, record where before taking the circuit apart.
