⬇️ DUMP CONTROL / VALVE PROBLEM

If the suspension will not inflate—or will not dump—diagnose the command and pneumatic path before replacing the valve.

1️⃣ DEFINE THE FAILURE: Won’t dump, won’t reinflate, dumps by itself, intermittent, or only under a certain key/parking-brake/vehicle condition?
2️⃣ KNOW THE SYSTEM: Identify whether the application uses pneumatic, electric/pneumatic or electronically managed dump control and what interlocks are designed into it.
3️⃣ COMMAND: Verify the switch/module command and relevant power, ground, signal or pneumatic pilot supply using the exact wiring/air diagram.
4️⃣ VALVE RESPONSE: Confirm whether the control valve actually changes state when commanded. A correct command with no response is different from a valve that is never being told to move.
5️⃣ AIR PATH: Inspect supply, exhaust, lines and height-control interaction. Restricted or misrouted plumbing can imitate a failed dump valve.
6️⃣ VERIFY: Cycle dump and reinflate functions through the manufacturer-defined operating conditions and confirm correct ride height.
DEFINE FAILURE → SYSTEM DESIGN → COMMAND → VALVE RESPONSE → AIR PATH → HEIGHT CONTROL → CYCLE / VERIFY.
⚠️ Dumping the suspension can lower the chassis suddenly. Keep personnel clear and mechanically support the vehicle before service.
