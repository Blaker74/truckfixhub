TRUCKFIXHUB FAULT-CODE GUIDE

SPN 3226 — Outlet NOx Sensor

Use the complete SPN/FMI and companion faults before deciding a NOx sensor needs replacement.

Diagnostic areas

  • Record the FMI and all related aftertreatment faults.
  • Inspect the sensor harness, connector, power/ground and heat damage.
  • Check for exhaust leaks that can affect aftertreatment readings.
  • Compare inlet/outlet NOx information using appropriate diagnostic software.
  • Consider DEF dosing and SCR performance when efficiency faults are also present.

Do not parts-cannon a NOx code

An SPN points to the monitored parameter; the FMI helps describe how it failed. A communication/electrical fault and an implausible performance reading require different testing. Confirm the fault before replacing the sensor.

Important
