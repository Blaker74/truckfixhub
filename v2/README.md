# TruckFixHub 2

Rebuild branch. The original production site remains untouched.

## Design rule
See it → tap it → understand it → go deeper only when needed.

## Rebuilt surface
- Simple visual home
- Visual system knowledge hub
- Engine, brakes, electrical, air, wheel end, emissions, cooling, driveline symptom doorways
- Functional client-side knowledge filtering
- Functional My Parts Room storage/search
- Functional My Trucks/VIN storage
- Deep links into the established TruckFixHub knowledge, fault-code, diagrams, repair-guide, shop-directory, community and contact resources

## Privacy note
Parts Room and My Trucks currently use browser localStorage in the rebuild prototype. Production private multi-device storage should move behind authenticated Supabase RLS before public launch.
