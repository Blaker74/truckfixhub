👇 Follow the evidence

🎵 WHINE / HOWL: Write down acceleration, coast, steady throttle and turning behavior. Verify lubricant, then separate tires, wheel ends and driveline before internal gearset diagnosis.
🔨 CLUNK: Inspect U-joints, yokes, slip splines, mounts and axle-location components. Total driveline lash can stack across multiple parts.
💧 PINION LEAK: Confirm source, level/specification, venting, yoke sealing surface and input/bearing condition. A new seal does not repair a moving shaft or damaged sealing surface.
🚫 NO DRIVE: Follow torque from transmission output through driveshaft, axle input, differential/power divider, axle shafts and hubs. Find the first point where torque stops.
🚛 TANDEM / POWER DIVIDER: Identify the exact tandem configuration. Separate switch/air/electrical command from actuator engagement and internal torque transfer.

🧠 Noise map

UNDER PULL: Record noise while torque loads the drive side of the system.
ON COAST: Torque reversal can change gear/bearing noise and driveline lash.
STEADY SPEED: Helps distinguish load-sensitive noise from road-speed rotating noise.
TURNING: Changing wheel speed/load can expose tire, wheel-end or differential behavior.

🔨 CLUNK ON TAKEOFF / PULL-COAST

Driveline lash can stack through several components. Find where the movement actually lives.

1️⃣ DEFINE THE EVENT: First takeoff, every shift, throttle on/off, forward/reverse transition, loaded or empty?
2️⃣ DRIVESHAFT: Safely inspect U-joints, yokes, slip splines and center/support components as equipped for looseness, binding or movement.
3️⃣ MOUNTS / AXLE LOCATION: Engine/transmission mounts and suspension torque rods/bushings can allow movement that feels like internal differential lash.
4️⃣ AXLE INPUT: Inspect applicable input/pinion and tandem inter-axle components using manufacturer procedures before opening the carrier.
5️⃣ INTERNAL LASH: If external components are proven sound and movement is isolated inside the axle, continue with the exact axle manufacturer’s differential/gearset inspection.
6️⃣ VERIFY: Repeat the same torque reversal and load condition after repair.
DEFINE TORQUE REVERSAL → U-JOINTS / YOKES / SPLINES → MOUNTS / AXLE LOCATION → AXLE INPUT → INTERNAL ONLY IF ISOLATED → VERIFY.
⚠️ Never inspect or handle a rotating driveshaft. Secure the vehicle and remove stored motion/energy before checking driveline movement.

🚫 NO DRIVE — REAR AXLE PATH

Do not guess which major assembly failed. Follow torque until it stops.

1️⃣ DEFINE THE FAILURE: No movement in any gear? One direction? Intermittent? Noise when power is applied? Did failure happen suddenly under load?
2️⃣ TRANSMISSION OUTPUT: Confirm the transmission/output is actually delivering torque before blaming the axle.
3️⃣ DRIVESHAFT / INPUT: Inspect the torque path through yokes, U-joints, shafts and axle input without exposing personnel to rotating components.
4️⃣ TANDEM CONFIGURATION: Identify forward/rear drive axle, power divider/inter-axle differential and lock controls. Tandem architecture changes how a broken component can affect movement.
5️⃣ DIFFERENTIAL → AXLE SHAFTS → HUBS: Determine the first stage where torque no longer transfers. Broken axle shafts or hub-side concerns can imitate a carrier failure.
6️⃣ VERIFY: After the proven repair, verify normal torque transfer and applicable lock/power-divider operation under manufacturer-approved conditions.
TRANSMISSION OUTPUT → DRIVESHAFT → AXLE INPUT → POWER DIVIDER / DIFFERENTIAL → AXLE SHAFTS → HUBS → VERIFY.
⚠️ Do not run a vehicle on unsupported drive axles or work around rotating driveline components. Follow OEM diagnostic and support procedures.

💧 PINION SEAL KEEPS LEAKING

A repeat leak means the seal may be the victim instead of the cause.

1️⃣ CONFIRM THE SOURCE: Clean the area and trace where lubricant begins. Do not confuse engine/transmission/driveline contamination with an axle input leak.
2️⃣ LUBRICANT + VENT: Verify axle lubricant level/specification and inspect the axle vent/breather system as applicable. Pressure can encourage leakage.
3️⃣ YOKE / SEALING SURFACE: Inspect the exact sealing surface for grooves, corrosion, damage, runout concerns or incorrect parts.
4️⃣ PINION / INPUT CONDITION: Check applicable bearing movement and input condition using axle-manufacturer procedures. A moving shaft can defeat a new seal.
5️⃣ INSTALLATION HISTORY: Verify correct seal, installation depth/orientation/tools, yoke/fastener procedure and any required replacement hardware. Some axle designs have critical preload/retention procedures.
6️⃣ VERIFY: Correct the root cause, restore lubricant level and inspect after a representative road/load cycle.
CONFIRM SOURCE → LEVEL / VENT → SEALING SURFACE → INPUT / BEARINGS → INSTALLATION → ROOT CAUSE → VERIFY.
⚠️ Do not disturb pinion retention or preload without the exact axle manufacturer procedure. Incorrect service can damage the gearset.

🚛 POWER DIVIDER / INTER-AXLE PROBLEM

Tandem drives have an additional torque path. First determine whether the complaint is control, engagement or internal torque transfer.

1️⃣ IDENTIFY THE AXLE SYSTEM: Record axle manufacturer/model and the exact inter-axle differential/power-divider arrangement before testing.
2️⃣ DEFINE THE COMPLAINT: Won’t lock, won’t unlock, no drive, warning indicator, noise, bind, or failure only on low-traction surfaces?
3️⃣ COMMAND / CONTROL: Depending on design, verify switch request, air supply/lines, solenoid or electrical command and indicator logic before condemning internal hardware.
4️⃣ ACTUATION: Determine whether the locking mechanism actually moves/responds using the axle manufacturer’s procedure. A valid command does not prove mechanical engagement.
5️⃣ TORQUE PATH: If no-drive or abnormal transfer remains, follow torque through forward axle, inter-axle shaft and rear axle to isolate where transfer stops.
6️⃣ VERIFY: Confirm normal lock/unlock indication and torque distribution only under the operating conditions permitted by the manufacturer.
IDENTIFY SYSTEM → COMPLAINT → COMMAND → AIR / ELECTRICAL CONTROL → ACTUATION → TORQUE PATH → INTERNAL ONLY WHEN PROVEN → VERIFY.
⚠️ Improper differential-lock operation can cause driveline windup or component damage. Follow the vehicle/axle manufacturer’s engagement and road-use instructions.

🎵 DIFFERENTIAL WHINE / HOWL

Noise that follows road speed still needs to be separated from tires, wheel ends and driveshaft components before opening the axle.

1️⃣ WRITE DOWN THE CONDITION: Acceleration, coast, steady throttle, deceleration or turning? Record speed range, load and temperature.
2️⃣ VERIFY LUBRICANT: Check level, condition, correct lubricant specification and evidence of contamination or metal according to axle manufacturer procedures.
3️⃣ SEPARATE EXTERNAL SOURCES: Inspect tires, wheel ends, U-joints, yokes and driveline components. Chassis structure can transmit noise away from its true source.
4️⃣ INPUT / PINION: Inspect for applicable input/pinion looseness, seal leakage and bearing evidence using the manufacturer’s procedures and limits.
5️⃣ INTERNAL GEARSET: Only after the axle is isolated should ring-and-pinion contact, bearings, preload/backlash or differential components enter directed internal diagnosis.
6️⃣ VERIFY: Road-test under the same pull/coast/speed condition after the proven repair.
CONDITION → LUBRICANT → TIRES / WHEEL ENDS / DRIVELINE → INPUT / PINION → INTERNAL ONLY WHEN ISOLATED → VERIFY.
⚠️ Gearset setup is precision work. Use the exact axle model’s current bearing, preload, backlash and contact-pattern procedures.
