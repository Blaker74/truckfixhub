Detroit DD13 / DD15 / DD16 Aftertreatment Guide

DPF • DEF • SCR • NOx sensors • regeneration • derate

Start with the complete fault information

Record the SPN, FMI, whether the code is active or inactive, dash warnings, engine power condition and any recent repair work. A component named in a fault description is not automatically the failed component.

Common aftertreatment complaint areas

  • DPF / regeneration: frequent regen requests, incomplete regeneration, high soot loading or temperature-related faults.
  • DEF system: fluid quality, level, dosing and delivery concerns can affect SCR operation.
  • SCR efficiency: low conversion efficiency may involve multiple upstream or downstream conditions and requires proper diagnostics.
  • NOx sensors: sensor-related codes require wiring, connector, power and system-condition checks before parts replacement.
  • Derate: emissions faults can progress to reduced engine power. Capture all active codes because the first/root fault may be more useful than the derate code itself.

Useful first checks

  • Record every active SPN/FMI before clearing anything.
  • Inspect accessible wiring and connectors for damage, corrosion or loose connections.
  • Check for obvious exhaust leaks or damaged aftertreatment components.
  • Confirm DEF level and investigate contamination or fluid-quality concerns using proper service procedures.
  • Review recent repairs: a new symptom immediately after service can provide an important diagnostic clue.

Don't fire the parts cannon

An emissions fault can be the result of another system condition. Replacing a NOx sensor, DPF, DEF component or other expensive part based only on the fault-code name can waste money and leave the original problem unresolved. Follow the applicable OEM diagnostic procedure.
