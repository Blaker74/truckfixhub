FAULT CODE · ENGINE PROTECTION · DERATE

SPN 1569 FMI 31

Engine protection torque derate condition. In many applications, this is better understood as evidence that the control system is limiting torque because another condition exists—not as the root-cause fault itself.

What should you check first?

  1. Record every active and inactive fault before clearing codes.
  2. Look for the companion fault that appeared with or before SPN 1569.
  3. Record warning lamps and dashboard messages including stop-engine, emissions and aftertreatment warnings.
  4. Check for obvious engine-protection conditions such as temperature, fluid-level or pressure concerns using the correct OEM information.
  5. Determine when the power loss began and what the truck was doing at the time.

What does SPN 1569 FMI 31 mean?

SPN 1569 FMI 31 commonly appears when the engine control system is intentionally limiting available torque because another condition has triggered an engine-protection or emissions-related derate. The exact implementation varies by engine, vehicle and calibration.

The important diagnostic distinction is that the derate is an action taken by the control system. Diagnosis should identify the condition that caused the controller to take that action.

Why companion faults matter

If SPN 1569 is accompanied by another active fault, that companion code often provides a more useful starting point. The underlying condition might involve engine protection, aftertreatment, sensor information, wiring or another monitored system. Treat the complete code set as one diagnostic story rather than separate automatic parts orders.

Save active and inactive codes. An inactive code can sometimes help establish what happened before the derate became obvious.

Engine-protection clues worth recording

  • Coolant temperature and any overheating warning
  • Oil-pressure or other lubrication warnings
  • Coolant or other monitored fluid-level warnings
  • Stop-engine or check-engine lamp status
  • Whether the engine still starts and idles normally
  • Whether power loss is constant or occurs under load
  • Recent engine, cooling, electrical or sensor work

Do not assume a generic specification applies. Compare measurements with the correct manufacturer information for the exact engine and application.

Could aftertreatment cause SPN 1569?

Depending on the application, emissions and aftertreatment conditions can be associated with operating restrictions or derates. If DEF, SCR, NOx, DPF or inducement faults are also present, diagnose those faults using the appropriate manufacturer procedure rather than focusing only on SPN 1569.

Will clearing SPN 1569 restore full power?

Clearing a fault is not the same as correcting the condition that triggered the torque limitation. The code or derate can return if the underlying problem remains, and some applications require manufacturer-specific verification or recovery steps after repair.

Preserve the evidence first, repair the cause, then verify operation according to OEM procedures.

Build a useful diagnostic record

  • Complete SPN/FMI list and active/inactive status
  • Warning lamps and dash messages
  • Engine make, model and serial number when available
  • Operating conditions when the derate began
  • Recent repairs or service
  • Tests performed
  • Underlying cause and verified repair

This turns “truck is derated” into information a technician can actually work with.

Do not ignore an engine-protection derate

A derate is the control system limiting operation for a reason. If the truck displays stop-engine warnings, unsafe operating conditions, abnormal temperature or pressure indications, or severe loss of power, follow manufacturer guidance and obtain qualified repair assistance. Do not bypass protection or emissions systems.
